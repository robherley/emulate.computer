Welcome to emulate.computer

This is a small Alpine Linux computer running on an emulated RISC-V CPU
inside your browser.

Try these in the Console or a Desktop Terminal:

  uname -a             See what is running
  python3 script.py     Run the Python example
  qjs script.js         Run the JavaScript example
  curl https://example.com

Files belong to this browser session, closing the tab will discard them.

Source: https://github.com/robherley/emulate.computer
