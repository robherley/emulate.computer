emulate.computer

A small Linux computer running inside your web browser. The emulator is written in Rust and compiled to WebAssembly.

The computer

The processor is a single-core, 64-bit RISC-V RV64GC CPU. It supports integer arithmetic, multiplication and division, atomic operations, single- and double-precision floating point, and compressed instructions, plus selected bit-manipulation and cryptography extensions.

The guest runs Alpine Linux with 128 MiB of RAM and a 512 MiB disk. Its desktop uses the Fluxbox window manager and the XLibre X server.
